# 🧬 ชีววิทยา By ADHD made

เว็บเกมควิซชีววิทยาระดับมัธยมปลาย (ม.4–ม.6) แบบ **ไร้หลังบ้าน (no backend)** ข้อมูลผู้ใช้ ความคืบหน้า และคะแนนถูกเก็บไว้ในเบราว์เซอร์ของผู้ใช้ด้วย `localStorage`

## ✨ ฟีเจอร์

- **โหมดการเรียน 6 โหมด** — ชีววิทยา ม.4 เทอม 1, ม.4 เทอม 2, ม.5 เทอม 1, ม.5 เทอม 2, ม.6 เทอม 1, ม.6 เทอม 2
- **โหมดพิเศษ**
  - 🎲 *รวมทุกเนื้อหา (สุ่ม)* — สุ่มคำถามจากทุกบท
  - 🔁 *ทบทวนข้อที่เคยตอบผิด* — รวมข้อที่ผู้ใช้ตอบผิดไว้ให้กลับมาทวน
- **สุ่มใหม่ทุกครั้ง** — สลับลำดับข้อและสลับตัวเลือกทุกครั้งที่เล่น
- **เฉลยทันที** — ตอบปุ๊บรู้เลยว่าถูก/ผิด พร้อม *คำอธิบายละเอียด* ที่เข้าใจได้แม้ไม่เคยเรียนมาก่อน
- **วิเคราะห์จุดอ่อน/จุดแข็ง** — แยกสถิติตามบทเรียน บอกว่าอ่อนหรือแข็งตรงไหน
- **แฟลชการ์ดทวนความจำ** — การ์ดคำศัพท์สำคัญ แตะเพื่อพลิกดูคำตอบ
- **คลังความรู้** — สรุปเนื้อหาแต่ละบทแบบเข้าใจง่าย
- **ความจำของระบบ** — จำผู้ใช้เดิม คะแนน และประวัติการเล่นด้วย `localStorage`

## 🚀 วิธีใช้งาน

เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้เลย (ไม่ต้องติดตั้งอะไร)

หรือโฮสต์ฟรีบน **GitHub Pages**:
1. ไปที่ Settings → Pages
2. เลือก Source: `Deploy from a branch`, Branch: `main` / `root`
3. รอสักครู่แล้วเข้าใช้งานผ่าน URL ที่ได้

## 🗂️ โครงสร้างโปรเจกต์

```
.
├── index.html            # หน้าหลัก (โหลดข้อมูล + สคริปต์)
├── assets/
│   ├── style.css         # ธีมของเว็บ
│   └── app.js            # ตัวโปรแกรมหลัก (ควิซ/แฟลชการ์ด/สถิติ/ความจำ)
└── data/
    ├── m4-1.js           # ข้อสอบ + สรุป + คำศัพท์ ชีววิทยา ม.4 เทอม 1
    ├── m4-2.js
    ├── m5-1.js
    ├── m5-2.js
    ├── m6-1.js
    ├── m6-2.js
    └── knowledge.js
```

## ➕ วิธีเพิ่มข้อสอบ

แก้ไขไฟล์ในโฟลเดอร์ `data/` รูปแบบข้อมูล:

```js
window.BIO_DATA["m4-1"].chapters.push({
  title: "ชื่อบท",
  notes: ["สรุปเนื้อหา 1 บรรทัด", "..."],
  terms: [{ term: "คำศัพท์", def: "คำอธิบาย" }],
  questions: [
    {
      concept: "หัวข้อย่อย",
      q: "คำถาม?",
      choices: ["ตัวเลือก ก", "ข", "ค", "ง"],
      answer: 0,               // ดัชนีคำตอบที่ถูก (เริ่มจาก 0)
      explanation: "คำอธิบายละเอียด"
    }
  ]
});
```

> โปรแกรมจะสุ่มลำดับข้อและสลับตัวเลือกให้เองอัตโนมัติ
